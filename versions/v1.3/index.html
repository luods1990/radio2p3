使用帮助

听广播：轻点电源开机；按住机身侧面的调谐拨盘拖动可以调台，也可以在底部电台列表里直接选台；拖动音量条调节音量。转动机身时，声音会随喇叭朝向变化。
看拆解：拖动“组装 ↔ 分解”滑杆拆开机器；点任一零件查看它的作用；单指拖动旋转视角，双指缩放。

数据来源与说明

外形依据公开资料与实物照片建模；元件位号与参数按典型 2P3 电路整理，个别数值可能因套件批次不同而有差异。中波频率据公开中波频率表（湖北全省 + 中央台），部分频率可能已调整；每台配多个直播源（蜻蜓FM / 央广云听等），连不上会自动换下一个。需联网收听。
